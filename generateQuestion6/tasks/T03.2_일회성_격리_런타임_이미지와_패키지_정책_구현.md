## 구현 범위
1. 비특권 사용자, 읽기 전용 루트, 실행별 임시 쓰기 공간을 사용한다.
2. SymPy와 승인된 표준 수학·속성 테스트 패키지 버전을 고정한다.
3. 네트워크·DNS·동적 패키지 설치·호스트 mount를 차단한다.
4. 입력 파일 하나와 결과 JSON 하나만 교환하는 runner를 만든다.

## 테스트 우선 실행 순서
1. 첫 필수 테스트를 작성하고 해당 테스트만 실행한다.
2. 의도한 이유로 실패하는지 확인한다.
3. 테스트를 통과시키는 최소 구현을 작성한다.
4. 모듈 전체 테스트와 관련 통합·보안 테스트를 실행한다.
5. 정적 검사 후 증거와 운영 문서를 갱신한다.

## 필수 테스트와 판정 기준
- [ ] **T03.2-ST1:** 외부 HTTP·DNS 연결이 모두 실패한다.
- [ ] **T03.2-ST2:** 환경변수·호스트 파일·소켓을 통해 비밀정보를 읽을 수 없다.
- [ ] **T03.2-ST3:** pip·패키지 매니저와 시스템 명령으로 패키지를 추가할 수 없다.
- [ ] **T03.2-ST4:** 실행 A가 실행 B의 임시 파일을 볼 수 없다.
- [ ] **T03.2-ST5:** 이미지 digest와 패키지 버전이 증거에 기록된다.
