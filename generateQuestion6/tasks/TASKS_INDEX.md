## 🧪 수동 스모크 (T08.1) — 라이브 LLM 파이프라인 실행 전 확인 사항

> 자동 회귀(ruff / mypy / pytest / eslint / tsc / vitest)는 커밋 시점에 전부 통과했습니다.
> 아래는 실행 중인 시스템을 브라우저에서 눈으로 확인하는 단계입니다. **LLM 호출이 실제 비용을 발생시키므로
> 기본 점검은 원문제 입력 → 파이프라인 실행이 아닌, 문제 라이브러리·진행 화면·로딩/오류 상태까지만 확인합니다.**

1. **백엔드 기동** — `.venv\Scripts\python -m uvicorn src.math_variant.main:app --reload` (루트에서 실행)
2. **프론트엔드 기동** — `npm run dev` (`web/` 디렉터리에서 실행, http://localhost:3000)
3. **홈(/)** — 헤더 액션 2개(새 문제 만들기 / 문제 라이브러리) 노출 및 링크 정상 동작
4. **문제 라이브러리(/problems)** — 문제 등록(제목+본문) → 목록 반영, 삭제 동작, 빈 상태 문구
5. **생성(/create)** — 원문제 텍스트 입력, 옵션 선택, 「생성 시작」 버튼 활성/비활성 전환, 취소 링크
6. **진행(/runs/{id}/progress)** — SSE로 단계 체크리스트(진행·완료·실패 색상)와 LLM 호출 로그 갱신,
   완료 시 「검토 화면으로 이동」 링크 → /runs/{id}/review 렌더링(승인·반려 동작)
7. **가격이 우려되는 실제 LLM 파이프라인 실행**은 로컬 목 공급자(없으면 `IDEATOR_COUNT=1`)로 대체해
   한 번만 확인하고, 승인 시 문제 라이브러리에 자동 보관되는지 확인

> 💡 실패 복구: 파이프라인 도중 오류가 나면 진행 화면에 재연결 버튼이 보이고, SSE 재연결로 로그가 이어집니다.
