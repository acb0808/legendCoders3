## 구현 범위
1. 허용 수식 노드와 기호 선언을 기준으로 파싱한다.
2. raw AST, alpha-renamed, AC-normalized, expanded, factored, rational-normalized view를 보존한다.
3. 비가환 연산에는 교환·결합 정규화를 적용하지 않는다.
4. 부동소수점보다 Integer·Rational을 우선하고 정의역·가정을 기호와 연결한다.

## 테스트 우선 실행 순서
1. 첫 필수 테스트를 작성하고 해당 테스트만 실행한다.
2. 의도한 이유로 실패하는지 확인한다.
3. 테스트를 통과시키는 최소 구현을 작성한다.
4. 모듈 전체 테스트와 관련 통합·보안 테스트를 실행한다.
5. 정적 검사 후 증거와 운영 문서를 갱신한다.

## 필수 테스트와 판정 기준
- [ ] **T02.2-UT1:** 1/2, 0.5, sqrt(4)/4가 정확 산술 비교에서 동치다.
- [ ] **T02.2-UT2:** 변수명만 다른 동형 식이 같은 alpha-renamed 지문을 가진다.
- [ ] **T02.2-UT3:** 행렬곱·함수합성 순서는 정규화로 바뀌지 않는다.
- [ ] **T02.2-UT4:** 미선언 함수·임의 Python 표현은 파싱 단계에서 거부된다.
- [ ] **T02.2-PT1:** 임의 유효식의 정규화 전후가 정의역 안 표본에서 동치다.
