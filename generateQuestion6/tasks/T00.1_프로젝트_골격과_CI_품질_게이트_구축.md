## 구현 범위
1. Python 3.12 패키지와 테스트 디렉터리를 생성한다.
2. 백엔드 lint·type check·unit test와 프론트 lint·unit test 명령을 정의한다.
3. CI가 백엔드와 프론트 검사를 병렬 실행하고 하나라도 실패하면 병합을 막게 한다.
4. 샌드박스 이미지와 운영 배포는 이 작업에 포함하지 않는다.

## 테스트 우선 실행 순서
1. 아래 첫 필수 테스트를 작성한다.
2. 해당 테스트만 실행해 의도한 이유로 실패하는지 확인한다.
3. 테스트를 통과시키는 최소 구현을 작성한다.
4. 해당 테스트와 같은 모듈의 전체 테스트를 실행한다.
5. 정적 검사와 관련 통합 테스트를 실행한다.
6. 코드·테스트·문서가 완료 게이트를 만족할 때만 리뷰를 요청한다.

## 필수 테스트와 판정 기준

- [ ] **T00.1-UT2:** 예제 구현 후 백엔드 pytest, 정적 검사, 프론트 테스트가 모두 0 코드로 종료되는지 확인한다.
