# 데이터 계약 및 운영 주의사항

> MVP 구현(문서 04 작업 지침 + 태스크 데이터베이스)을 반영한 데이터 계약과 운영 시 유의사항.

## 1. 핵심 도메인 계약 (`src/math_variant/domain/`)

### ProblemSpec
- `core_concepts`는 범위 밖 개념이면 `SCOPE_VIOLATION`으로 거부된다.
- `unresolved_assumptions`가 비어 있지 않으면 자동 생성 경로가 차단된다. (fail-closed)
- `answer_type`은 허용된 리터럴 집합으로 제한된다.

### TransformationPlan
- 변경 차원이 4개 미만이면 `PLAN_CHANGE_DIMENSION_SHORTAGE`.
- 구조적 변경이 2개 미만이면 `PLAN_STRUCTURAL_CHANGE_SHORTAGE` (단순 숫자·표현 치환 차단).

### CandidateProblem
- `final_answer_claim`은 검증 전 주장일 뿐이며 `verification_status` 기본값은 `UNVERIFIED`다.
  주장 답만으로 PASS 상태가 자동 부여되는 경로는 없다.

### ValidationEvidence
- `CheckResult.status`는 필수이며 기본값이 없다 (미검증을 PASS로 표현 금지).
- `counterexample`가 있으면 상태가 `PASS`일 수 없다.
- 직렬화 결과에 `tool_version`, `code_version`, `input_hashes` provenance가 남는다.

## 2. 공급자 계약 (`src/math_variant/providers/`)

- 비즈니스 코드는 모델명 대신 `RolePolicy`(source_analyzer/generator/blind_solver/critic)만 참조한다.
  공급자·모델·폴백은 `RolePolicyConfig` + `build_provider_registry`가 결정한다 (CT5).
- 응답은 서버에서 Pydantic으로 재검증한다. 복구 1회 + 폴백 1회까지만 시도하고,
  실패는 구조화된 오류(`ProviderErrorCode`)로 다음 단계에 전달되지 않는다.
- 공급자 로그에서 API 키·전체 민감 프롬프트는 제거된다(`redact_secrets`).

## 3. 샌드박스 계약 (`src/math_variant/sandbox/` + `infra/sandbox/`)

- `SandboxRequest`는 비밀 타입 필드를 참조할 수 없고, input_json·code에
  API 키/DB URL/호스트 경로 패턴이 있으면 거부된다.
- 상태: `COMPLETED | CODE_ERROR | TIMEOUT | POLICY_VIOLATION | INFRA_ERROR`.
- 운영 경계는 격리 이미지다: `--network none --read-only --memory 제한 --tmpfs /work`.
- 입력은 base64로 stdin, 결과는 stdout JSON 하나. 이미지 digest와 패키지 버전이 증거에 기록된다.

### 샌드박스 이미지 재현
```bash
docker build -t math-variant-sandbox:test infra/sandbox
docker image inspect math-variant-sandbox:test --format '{{index .RepoDigests 0}}'
```

## 4. 검증 게이트

- Source Gate: `PASS`일 때만 계획 단계로 전이.
  - `UNSATISFIABLE_SOURCE` / `AMBIGUOUS_OR_MULTI_SOLUTION` / `SOURCE_UNRESOLVED` / `SOURCE_ANSWER_MISMATCH`는 차단.
- 블라인드 풀이 합의: 두 독립 풀이자의 정규화 해집합이 동치이고 정의역·핵심 단계가 충돌하지 않아야 `PASS`.
  판단 불능이 하나라도 있으면 자동 승인 없음.
- 규칙 카탈로그: 상충 규칙 조합은 `RULE_CONFLICT`, 계획 밖 기호/차원은 `PLAN_DRIFT`,
  복제 패턴은 `SURFACE_BLACKLIST`로 거부.

## 5. 운영 주의사항

- 로컬 개발용 `LocalSandboxProvider`는 신뢰 경계가 아니며 운영에서 사용하면 안 된다.
- 실제 LLM 호출이 필요한 테스트는 `MATH_VARIANT_LIVE_PROVIDER_TESTS=1`에서만 실행된다.
- 도커 격리 테스트는 docker 데몬이 없으면 자동 skip된다.
- 교사 화면(Next.js)은 FastAPI(`src/math_variant/api/app.py`)를 통해서만 데이터를 받는다.
  검토 화면은 검증(PASS) 후보만 노출하며, 반려는 사유 코드가 필수다.
- `runs/`(실행 산출물)과 `.env`는 git 에 커밋하지 않는다 (.gitignore).
